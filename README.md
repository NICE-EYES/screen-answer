# Screen Answer

Десктопный помощник для Windows 10/11: делает скриншот экрана (или выбранной области), распознаёт текст,
определяет, что на экране (тест, код, ошибка, таблица, график, документ, иностранный текст…), и отвечает
на ваши вопросы в маленьком плавающем окне поверх всех приложений.

Программа **только смотрит** на экран: она не кликает, не печатает, не переключает окна и вкладки
и не управляет браузером.

## Установка

### 1. Python

1. Скачайте Python 3.10 или новее: <https://www.python.org/downloads/windows/>.
2. В установщике **обязательно** отметьте «Add python.exe to PATH».
3. Проверьте в PowerShell:

```bash
python --version
```

### 2. Tesseract OCR для Windows

1. Скачайте установщик Tesseract 5 (сборка UB Mannheim): <https://github.com/UB-Mannheim/tesseract/wiki>.
2. При установке в разделе **Additional language data** отметьте **Russian** (английский ставится по умолчанию).
   Нужны и другие языки — отметьте их тоже.
3. Путь по умолчанию: `C:\Program Files\Tesseract-OCR\`. Программа найдёт его сама.
   Если вы установили Tesseract в другое место, укажите путь к `tesseract.exe` в **Настройки → OCR**.

### 3. Переменная окружения TESSDATA_PREFIX

Обычно программа сама находит папку `tessdata` рядом с `tesseract.exe`. Если появляется ошибка
«Нет языковых данных Tesseract», задайте переменную вручную:

```bash
setx TESSDATA_PREFIX "C:\Program Files\Tesseract-OCR\tessdata"
```

После `setx` закройте и заново откройте терминал. Вместо этого можно указать путь в поле
**Настройки → OCR → TESSDATA_PREFIX**. Проверить установку можно кнопкой «Проверить Tesseract» там же.

### 4. Виртуальное окружение

Откройте PowerShell в папке проекта:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

Если PowerShell запрещает запуск скриптов, выполните один раз:

```bash
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 5. Установка зависимостей

```bash
pip install -r requirements.txt
```

По желанию — альтернативные OCR-движки (EasyOCR ставит PyTorch, это 1–2 ГБ):

```bash
pip install -r requirements-optional.txt
```

### 6. Запуск

```bash
python main.py
```

Чтобы запускать без окна консоли, используйте `pythonw main.py`. Справа вверху появится плавающее окно,
а в системном трее — значок программы.

Собрать `.exe` (необязательно):

```bash
pip install pyinstaller
```

```bash
pyinstaller --noconsole --onedir --name ScreenAnswer main.py
```

## API-ключ OpenAI

1. Зарегистрируйтесь на <https://platform.openai.com/>.
2. Пополните баланс в **Settings → Billing**: без положительного баланса API возвращает ошибку
   `insufficient_quota`.
3. Откройте <https://platform.openai.com/api-keys> → **Create new secret key** → скопируйте ключ (`sk-...`).
   Ключ показывается один раз.
4. В программе: **⚙ → вкладка «ИИ» → API-ключ** → вставьте ключ → «Проверить подключение» → «Сохранить».
5. На вкладке **«Конфиденциальность»** включите «Использовать облачный ИИ» и подтвердите предупреждение.

Вместо поля в настройках можно задать переменную окружения (тогда ключ не попадёт в `config.json`):

```bash
setx OPENAI_API_KEY "sk-ваш-ключ"
```

> Ключ из поля настроек хранится в `config.json` открытым текстом. Не публикуйте этот файл: он уже
> добавлен в `.gitignore`.

Модель по умолчанию — `gpt-4o-mini`: она дешёвая и принимает изображения. Для сложных задач выберите
`gpt-4o`/`gpt-4.1` или более новую модель с поддержкой изображений. Поле «Адрес API» позволяет
подключить любой OpenAI-совместимый сервер (например, локальный).

## Как выбрать область экрана

Кнопка **🔲 Область ▾** в окне:

| Пункт | Что анализируется |
|---|---|
| **Весь экран: монитор N** | весь выбранный монитор |
| **Все мониторы** | весь рабочий стол (показывается, если мониторов больше одного) |
| **Активное окно** | окно, которое было активным последним (не окно Screen Answer). Просто щёлкните по нужному окну — программа запомнит его и будет снимать только его границы. |
| **✂ Выделить область мышью…** | экран затемнится, зажмите левую кнопку и обведите нужный прямоугольник. Esc или правая кнопка — отмена. |
| **Выделенная область** | вернуться к ранее выделенной области |

Совет: для тестов и кода выделяйте только блок с вопросом/кодом. Так распознавание точнее,
ответ лучше, запрос дешевле, а лишние личные данные не уходят в облако.

Текущая цель показана под кнопками («Цель: …»).

## Режимы работы

**Вопрос по экрану.** Введите вопрос («Что здесь спрашивают?», «Объясни этот код», «Какой вариант
правильный и почему?», «Переведи текст», «Найди ошибку», «Объясни график», «Сделай пересказ») и нажмите
**Спросить** или Enter. Программа сделает свежий снимок, распознает текст и отправит модели скриншот,
текст, вопрос и 3–5 последних вопросов и ответов. Ответ появляется по мере генерации.
Пустой вопрос означает «проанализируй экран и ответь».

**Автоматический анализ.** Включите **Авто**. Раз в 5–60 секунд (ползунок «Частота») программа делает
снимок. Если экран не изменился, статус показывает «нет изменений», и запрос никуда не уходит.
Если изменился, программа локально распознаёт текст и показывает подсказку: «Открыт тест с 4 вариантами
ответа», «Обнаружена ошибка в коде», «На экране таблица…». По умолчанию автоанализ **не тратит API**.
ИИ-сводку можно включить в Настройках → Захват.

**📸 Снимок** — снимок и распознавание прямо сейчас, без запроса к ИИ.

**🎤 Голос** — нажмите, задайте вопрос, нажмите ещё раз. Речь распознаётся через API
(модель `whisper-1`), затем вопрос задаётся автоматически.

### Горячие клавиши (глобальные, меняются в настройках)

| Сочетание | Действие |
|---|---|
| **Ctrl+Alt+S** | сделать скриншот и ответить (берётся текст из поля вопроса, если он есть) |
| **Ctrl+Alt+Q** | открыть окно и поставить курсор в поле вопроса |
| **Ctrl+Alt+H** | скрыть / показать окно |
| **Ctrl+Alt+X** | полностью остановить анализ (автоанализ, текущий запрос, запись голоса) |

### Окно

- всегда поверх других окон, перетаскивается за заголовок, размер меняется уголком справа внизу;
- **▁** (или двойной щелчок по заголовку) сворачивает окно в узкую полоску со статусом;
- **✕** прячет окно в системный трей, а щелчок по значку в трее возвращает его;
- **◐** переключает тёмную и светлую тему, ползунок «Прозрачн.» меняет прозрачность от 10 до 100 %;
- индикатор состояния: серый — ожидание, жёлтый — снимок/распознаю/анализирую, зелёный — готово,
  синий — нет изменений, красный — ошибка;
- разделы «Распознанный текст» и «История ответов» раскрываются по щелчку;
- «Очистить историю» очищает окно и контекст диалога, «Стереть историю» безвозвратно удаляет базу.
- Выход из программы: правый щелчок по значку в трее → «Выход».

## Конфиденциальность

- OCR выполняется **локально** (Tesseract по умолчанию).
- **Облачный ИИ по умолчанию выключен.** При включении программа предупреждает, что на изображении
  экрана могут быть личные данные.
- Переключатель **«Не отправлять скриншоты в облако»**: модели уходит только распознанный текст.
- Скриншоты **не сохраняются на диск**, пока вы не включите это в настройках.
- История хранится только локально в SQLite (`history.db`); её можно отключить или стереть кнопкой.
- На время снимка окно программы на долю секунды становится прозрачным, чтобы не попасть на скриншот
  (отключается в настройках).

## Почему программа не сворачивает браузер и не переключает вкладки

В программе нет кода, который мог бы управлять компьютером:

1. **Захват экрана** идёт через `mss`: эта библиотека читает готовое изображение рабочего стола
   (GDI BitBlt) и не трогает окна.
2. **Режим «Активное окно»** только *читает* дескриптор и координаты активного окна
   (`GetForegroundWindow`, `DwmGetWindowAttribute`). Программа никогда не вызывает для чужих окон
   `SetForegroundWindow`, `ShowWindow`, `SendMessage` или подобные функции.
3. **Нет эмуляции ввода**: не используются `pyautogui`, `pynput`, `keyboard`, `SendInput`,
   `mouse_event` и т. п. Горячие клавиши регистрируются через `RegisterHotKey`: Windows лишь сообщает
   программе о нажатии её сочетания, а программа ничего не нажимает.
4. **Плавающее окно** открывается без перехвата фокуса (`WA_ShowWithoutActivating`, окно типа Tool),
   поэтому браузер или тест остаются активными. Фокус окно получает только по вашему действию
   (щелчок или Ctrl+Alt+Q).
5. **Ссылки в ответах не открываются** (`setOpenLinks(False)`), то есть браузер не запускается.
6. Системный промпт запрещает модели предлагать действия, требующие управления компьютером, а её ответ
   выводится только как текст в окне программы.

## Как снизить расход API

- **Анализ только при изменении экрана.** Кадр сравнивается с предыдущим по уменьшенной копии.
  Если изменилось меньше порога («Порог изменения экрана», 0,1 % по умолчанию), запрос не отправляется.
- **Автоанализ без ИИ.** По умолчанию подсказки в авторежиме строятся локально и бесплатно.
  Если включаете ИИ-сводку, задайте «Мин. интервал ИИ-сводок» (30 с и больше).
- **Сжатие скриншотов.** Изображение уменьшается до «Макс. стороны» (1600 px) и сжимается в JPEG
  (качество 75). Для крупного текста хватит 1024 px и детализации `low`: это в несколько раз дешевле.
- **Выделяйте область**, а не весь экран: меньше пикселей — меньше токенов и точнее ответ.
- **Только текст.** Если на экране обычный текст, включите «Не отправлять скриншоты»: текстовые
  токены значительно дешевле.
- **Короче история.** «Глубина истории» = 2–3 уменьшает объём каждого запроса.
- **Ограничьте частоту.** Интервал 30–60 с для автоанализа; Ctrl+Alt+X мгновенно всё останавливает.
- **Лимит токенов ответа** ограничивает максимальную стоимость одного ответа.
- Используйте `gpt-4o-mini` для повседневных вопросов, а более сильную модель — только для сложных.

## Решение проблем

| Проблема | Решение |
|---|---|
| «Tesseract не найден» | Установите Tesseract или укажите путь к `tesseract.exe` в Настройки → OCR |
| «Нет языковых данных» | Установите языковой пакет (Russian) или задайте `TESSDATA_PREFIX` |
| Текст распознаётся плохо | Выделите область крупнее, увеличьте масштаб страницы (Ctrl+колесо) или смените PSM на 6/11 |
| «сочетание уже занято» | Горячую клавишу заняла другая программа — назначьте другую в Настройки → Клавиши |
| 401 / 429 / insufficient_quota | Проверьте ключ и баланс на platform.openai.com |
| Модель не принимает изображения | Выберите `gpt-4o-mini` или `gpt-4o` |
| Окно пропало | Ctrl+Alt+H или щелчок по значку в трее |

Подробный журнал ошибок: `screen_answer.log` рядом с программой.
